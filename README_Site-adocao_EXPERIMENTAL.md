## ✨ Funcionalidades
- 🐶 Listagem de animais com fotos + cards
- 🔍 Filtros por porte/idade/status
- 📝 Formulário de adoção com validação
- 📱 Totalmente responsivo
- ⚡ Vite + ESLint + Prettier

## 🚀 Como rodar
```bash
git clone https://github.com/Lucas-Baumann/Site-para-adocao-de-animais
cd Site-para-adocao-de-animais
npm install
npm run dev
# abra http://localhost:5173
```

## 🛠️ Stack
`React • TypeScript • Vite • React Router • CSS Modules • ESLint`

## 📂 Estrutura
```
src/
 ├─ components/ # AnimalCard, FilterBar
 ├─ pages/      # Home, AnimalDetail
 └─ data/       # mock de animais
```
